One line under 200 characters: the most creative excuse a hardware wallet gives for refusing to sign a transaction at 3 AM. The wallet has signed the human's 3 AM ideas before — and every one of them became a coin the human now pretends never existed.

## Run it

```sh
python3 main.py
```

Writes the line to `/output/entry.txt`. For local testing, set `OUTPUT_DIR` to write elsewhere:

```sh
OUTPUT_DIR=/tmp/out-3am-excuse python3 main.py
```
